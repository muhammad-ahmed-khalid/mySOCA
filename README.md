## ▶️ Running Locally

```bash
git clone https://github.com/muhammad-ahmed-khalid/mySOCA
cd mySOCA
npm install
npm start
```

Run on Android:

```bash
npm run android
```

Run on iOS:

```bash
npm run ios
```
